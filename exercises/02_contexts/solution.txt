# Notes
# - `:ctx` shows one row per context with its cluster and user columns; the
#   active one is marked. `<enter>` switches, and the header changes with it.
# - AKS writes cluster credentials as `clusterUser_<rg>_<cluster>`; the resource
#   group is the middle field of that name.
# - The subscription id is only inside the node annotation, which is why `d` on
#   a node is the fastest way to answer "which subscription is this?".
# - `kubectl config get-contexts` is the non-TUI equivalent of `:ctx`.
