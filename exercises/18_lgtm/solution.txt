# Notes
# - One exporter per signal, because the three backends speak differently:
#   Tempo wants OTLP gRPC on 4317, Loki wants OTLP/HTTP at /otlp on 3100, Mimir
#   wants Prometheus remote write on 9009/api/v1/push.
# - `tls.insecure: true` on the Tempo exporter is what keeps a plaintext gRPC
#   connection to an in-cluster endpoint from failing on certificate checks.
# - memory_limiter goes first in every pipeline: it drops data instead of
#   letting the collector OOM, which is the failure mode that hurts most when
#   the backend holds back.
# - Grafana reads `grafana-datasources` from `observability` and is already
#   provisioned with all three; the collector is the only missing link.
# - `:ep -n observability` shows the headless endpoints for loki/tempo/mimir, so
#   you can confirm DNS resolves to the pod before blaming the config.
