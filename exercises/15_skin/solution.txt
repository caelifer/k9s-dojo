# Notes
# - Colours are quoted strings; unquoted #1e1e2e would parse as a YAML comment.
# - `k9s --invert` flips light/dark without touching the file; `--crumbsless`,
#   `--headless` and `--logoless` trim the chrome if a skin still feels busy.
# - A bad skin file does not stop k9s: it logs the error and falls back to the
#   default look, which is why the check validates the YAML rather than the
#   screen.
